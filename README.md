## Overview

This project allows users to browse a list of products, add them to a cart, adjust quantities, and confirm their order. The interface is fully responsive and provides a smooth user experience across devices.

## Features

- Add items to the cart and remove them
- Increase/decrease the number of items in the cart
- See an order confirmation modal when clicking "Confirm Order"
- Reset selections with "Start New Order"
- Responsive layout for all device sizes
- Accessible and interactive UI elements
